# 사전등록: MRI 화질 저하와 복원이 해마 분할과 부피 일치도에 주는 영향

결과를 보기 전에 쓴다. 판정 규칙은 결과를 본 뒤 바꾸지 않는다. 바꿀 일이 생기면 맨 아래 "수정 이력"에
날짜와 이유를 적고 원래 문장은 지우지 않는다.

## 1. 질문

1. 잡음, 바이어스 필드, 두꺼운 절편으로 화질이 떨어지면 배포 모델의 해마 부피 일치도(ICC, 일치 한계 폭)가 떨어지는가.
2. 떨어진다면 복원(고전 방법, 3D U-Net)이 얼마나 되찾는가.
3. 복원 없이 분할 모델을 저하 영상으로 미세조정하는 것보다 복원이 나은가.
4. 화질 지표(PSNR)가 오르는데 부피가 체계적으로 치우치는 경우가 있는가.

## 2. 자료와 모델

- 홀드아웃 52건(모델 선택에 쓰지 않은 것, `outputs/splits.json`). 평가는 기존 홀드아웃 평가와 같게 한다. 개발셋 5-fold 의
  SegResNet 체크포인트 다섯으로 각각 분할하고, Dice, HD95, ASD 는 체크포인트별 값의 평균, 부피 일치도(ICC(2,1), 일치 한계의 절반
  폭을 정답 평균 부피 대비 %로)는 다섯 예측 부피의 케이스별 평균(앙상블)으로 낸다. 후처리(최대 연결성분)도 같다.
- 저하가 없는 조건으로 이 평가를 돌리면 기존 홀드아웃 결과(Dice 0.8889, ICC 0.9341)가 그대로 나와야 한다. 나오지 않으면
  평가 경로가 다른 것이라 결과를 쓰지 않고 원인을 찾는다.
- 복원 모델 학습과 조정, 비교군 미세조정에는 개발셋 208건만 쓴다. 홀드아웃은 평가에만 쓴다.

## 3. 저하 모사

모두 1mm 재표본화 뒤, z-점수 정규화 전의 원래 세기에 건다. 케이스와 조건마다 고정 시드(파일 이름, 저하 종류, 세기에서 만든 값).

| 저하 | 방법 | 세기(주 조건은 가운데) | 근거 |
|---|---|---|---|
| 잡음(Rician) | 위상 0 을 가정해 실수부, 허수부에 표준편차 f x (뇌 영역 세기 중앙값) 의 가우시안을 넣고 크기를 취한다 | f = 0.03, 0.06, 0.10 (신호 대 잡음비 약 33, 17, 10) | 임상 T1 영상의 신호 대 잡음비가 대략 수십이라는 가정. 가속 촬영과 저자장 장비에서 더 낮아진다 |
| 바이어스 필드 | 곱하는 매끈한 장 exp(P), P 는 좌표를 -1\~1 로 둔 3차 다항식, 계수는 -c\~c 균등 | c = 0.025, 0.05, 0.1 (장의 최대/최소 비 중앙값 약 1.2, 1.45, 2.1) | 코일 불균일이 세기를 수십 % 바꾸는 범위. 케이스별 비를 실측해 함께 적는다 |
| 두꺼운 절편 | 위아래(S) 축으로 t 장씩 평균(부분 부피)한 뒤 1mm 로 선형 보간 | t = 2, 3, 4 mm | 임상 2D T1 의 절편 두께가 3\~5mm 인 점 |

한계: 공개 자료(Medical Decathlon Task04)는 해마 주변만 잘라 낸 작은 영상이라, 바이어스 필드가 머리 전체에서처럼 휘지 않는다.
MRI 잡음은 X선 잡음과 물리가 다르다.

## 4. 복원 방법

| 저하 | 고전 방법 | 학습 방법 |
|---|---|---|
| 잡음 | 3D 비국소 평균(`skimage.restoration.denoise_nl_means`), h = a x 추정 잡음. a 는 개발셋 40건의 PSNR 로 세기마다 고른다(격자 0.6, 0.8, 1.0, 1.2) | 3D U-Net |
| 바이어스 필드 | N4(`SimpleITK.N4BiasFieldCorrection`, Otsu 뇌 영역 마스크, 기본 설정). 조정 없음 | 3D U-Net |
| 두꺼운 절편 | 절편 가운데 값에서 삼차 스플라인으로 다시 보간 | 3D U-Net |

3D U-Net: MONAI BasicUNet, 저하 세 종류 세 세기를 섞어 한 모델(blind)로 학습한다. 입력과 목표는 저하 영상의 99 백분위로 나눈 값,
L1 손실, 개발셋 188건 학습 20건 검증, 검증 손실로 조기종료(인내 20, 최대 300 에폭), 시드 3개.

PSNR 은 분할 모델이 보는 것과 같게 두 영상을 z-점수 정규화(0 이 아닌 복셀)한 뒤 재고, 봉우리는 깨끗한 영상의 값 범위로 둔다.

## 5. 비교군

복원 없이 분할 모델을 저하 영상으로 미세조정한 경우. fold 마다 그 fold 의 체크포인트에서 시작해 그 fold 의 학습 목록으로, 케이스마다
저하 종류와 세기를 무작위로(저하 없음 포함) 골라 학습한다. 학습률 1e-4, 최대 100 에폭, fold 검증 목록에 고정 저하를 건 Dice 로
조기종료(인내 20). 다섯 fold 모델을 같은 방식(체크포인트 평균, 부피 앙상블)으로 저하 홀드아웃에 적용한다.

## 6. 판정 (주 지표 하나, 순서대로)

주 지표: 잡음 f = 0.06 에서 ICC 의 회복률(3D U-Net 시드 3개 평균).
회복률 = (복원 ICC - 저하 ICC) / (저하 없음 ICC - 저하 ICC).

1. 하락 확인: 저하 없음 ICC - 저하 ICC 의 95% 신뢰구간(케이스 부트스트랩 1,000회, 시드 42, 백분위)이 0 을 포함하면 회복률을
   계산하지 않고 "이 세기에서는 저하가 부피 일치도를 해치지 않았다"로 적는다.
2. 하락이 있으면 회복률과 그 신뢰구간을 적는다.
3. 복원이 따로 필요한가: 복원 ICC - 비교군 ICC 의 95% 신뢰구간이 0 보다 크면 "복원이 낫다", 0 보다 작으면 "미세조정이 낫다",
   0 을 포함하면 "차이를 확인하지 못했다".
4. 화질과 부피의 방향: 복원 뒤 PSNR 은 올랐는데 Bland-Altman 편향의 절댓값이 저하 영상보다 커진 경우를 센다.

나머지(다른 저하, 다른 세기, 고전 방법, Dice, HD95, 일치 한계 폭)는 보조 지표다. 보조 지표로 주 판정을 바꾸지 않는다.

## 7. 산출물

요약 수치는 `outputs/degradation_*.json` 에 둔다(`.gitignore` 가 `outputs/` 바로 아래의 JSON 만 올린다). 복원 모델, 미세조정
가중치, 로그는 `outputs/degradation/` 아래에 두어 올리지 않는다.

## 수정 이력

- 실행 전: 바이어스 필드 세기를 c = 0.2, 0.4, 0.6 에서 0.025, 0.05, 0.1 로 바꿨다. 다항식이 19항이라
  처음 값으로는 장의 최대/최소 비가 중앙값 4.4, 20, 87 배로 근거에 적은 범위(수십 %)를 넘었다. 저하 자체의 크기를 재서
  고친 것이고 어떤 결과도 보기 전이다.
- 실행 전: PSNR 을 원래 세기가 아니라 z-점수 정규화 뒤에 재기로 정했다. 사전 시험(홀드아웃 한 케이스)에서 N4 가
  영상 전체 밝기 배율을 바꿔 원래 세기 PSNR 이 11dB 로 떨어졌는데, 정규화 뒤의 영상을 보는 모델에는 배율이 영향이 없다.
  배포 모델이 학습 때 이미 가우시안 잡음과 바이어스 필드(계수 0\~0.1) 증강을 15% 확률로 받았다는 점도 여기서 확인했다.
  결과 해석에 적는다.
- 실행 전: 3D U-Net 복원기 학습에 학습률 줄이기를 넣었다. val L1 이 8에폭 나아지지 않으면 학습률을 반으로
  줄인다(최소 1e-6). 이 저장소의 분할 학습 설정(lr_patience 8, lr_factor 0.5)과 같은 규칙이다. mimic 저장소의 DnCNN 이
  학습률 1e-3 고정으로 흔들리다 한 시드가 배우지 못해, 같은 위험을 미리 막으려는 것이다. 조기종료(인내 20, 최대 300 에폭),
  시작 학습률 1e-3, 손실, 구조는 그대로다. 복원 없이 저하 영상 그대로의 val L1 을 함께 기록해, 학습이 그보다 나은지 결과
  파일에서 바로 보이게 했다. 이 단계는 아직 한 번도 돌지 않았다.
- 개발셋 조정 뒤(홀드아웃 평가 전), 비국소 평균 조정 격자(4절). 개발셋 40건 조정 결과(`outputs/degradation_tune.json`)에서 잡음 세 세기 모두 격자의
  가장 약한 끝 a = 0.6 이 골라졌다. f = 0.03, 0.06 에서는 가장 약한 세기도 잡음 그대로보다 PSNR 이 낮았다(40.92 대 37.78,
  35.46 대 35.00). mimic 저장소의 고전 복원에서도 같은 일이 있었고, 원래 영상에 이미 있는 잡음까지 지우면 기준
  영상과 견준 PSNR 에서 손해를 보는 것이 원인으로 보인다. 처리는 mimic 과 같다. 원래 격자의 결과를 주 분석으로 그대로 쓰고,
  원래 값을 모두 포함해 양쪽으로 넓힌 격자(0.1 \~ 1.5)로 다시 조정해 홀드아웃에 적용한 결과를 "사전등록 이탈, 보조 분석"
  (조건 이름 `noise0.06_nlmwide` 등, 산출물 `degradation_tune_wide.json`)으로 나란히 적는다. 이 결정은 개발셋 조정 결과만 보고
  내렸고 홀드아웃 결과는 보지 않았다. 주 지표(잡음 f = 0.06, U-Net 회복률)와 판정 순서는 바뀌지 않는다.
- 다시 실행 전: 분할을 피험자 단위로 바꿔 이 분석을 처음부터 다시 돌린다(`docs/prereg_pair_split.md`). 새 홀드아웃
  52건에는 같은 사람의 좌우가 함께 든 짝이 16쌍(피험자 36명) 있어, 1번의 "케이스 부트스트랩"을 피험자 단위 부트스트랩으로
  바꾼다(반복 1,000회, 시드 42, 판정 규칙은 그대로). 복원 U-Net 의 검증 20건도 피험자 단위로 고른다. 두 가지 모두 새 분할의
  어떤 결과도 보기 전에 정했다.
- 공개 전 정리: 날짜 표기를 단계 표기로 바꿨다. GitHub 에서 취소선으로 보이지 않게 물결표 앞에 역슬래시를 넣었다. 규칙과 결과는 바뀌지 않는다.
